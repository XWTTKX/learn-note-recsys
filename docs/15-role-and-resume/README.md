# 15 · 搜广推能力映射与简历

此项目重点支撑推荐/广告召回、CTR排序、序列兴趣、评测偏差和工程一致性。配合表情包搜索项目，能覆盖query理解与用户兴趣两条链。

广告岗位还需补CVR与延迟反馈、ESMM等任务关系、校准、竞价与预算约束；没有做过这些，不能仅将笔记推荐改名为广告投放项目。

## 当前阶段可写

“围绕公开Qilin笔记场景构建推荐实验基线，完成请求级数据适配、训练期ItemCF/热门召回及两种候选协议评测，分析冷启动与曝光偏差。”只有自己复现相应代码后才使用此描述。

## 实测完成后替换

“在[数据版本/候选池]上实现[召回方案]与[排序模型]，固定测试集[规模]下[指标]从[A]至[B]；通过[具体消融]定位[问题]，完成[服务一致性或性能验证]。”

不填虚构用户量、日活、QPS或线上收益。公开数据项目不能包装成小红书实习或内部上线项目。证据包含commit、数据许可、配置、运行日志、评价分母及失败记录。

岗位筛选时按JD映射已有证据，不用统一的大厂薪资或岗位趋势数字代替准备。技术面试仍需机器学习基础、概率统计和编码能力。
