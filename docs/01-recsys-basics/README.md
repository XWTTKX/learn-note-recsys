# 01 · 推荐基础与笔记信息流目标

搜索由query表达当下意图；推荐往往只有用户历史与上下文，需要主动选择候选。相同用户在不同时间可能想看不同内容，不能只把用户ID当固定兴趣。

笔记推荐的教学目标是：从内容池产生候选，预测用户偏好，再兼顾多样性和新内容。我们使用公开Qilin笔记场景建立项目，不声称复原小红书线上生产系统。

## 业务目标与可观测标签

曝光是产生点击机会的前提，点击、阅读、收藏和点赞不是同一个目标。只追点击可能偏向标题党；只追停留可能偏向长内容。是否可做多任务，取决于数据是否有可靠标签、缺失语义和时间窗口。

离线日志记录的是历史策略挑选过的内容，未出现的内容是“未观测”，不能直接认为用户不喜欢。当前基线学习点击共现，不是经过校准的点击率模型。

验收：画出一次推荐请求的输入（历史、候选、上下文）与输出（有序笔记列表）；解释为什么推荐的历史不能含本次请求的点击结果。
