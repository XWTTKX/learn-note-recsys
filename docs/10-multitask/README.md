# 10 · 多目标、重排与冷启动

## 点击、收藏和停留不能随手相加

如果收藏只在点击后观察，联合概率可拆成 $P(收藏且点击)=P(点击)P(收藏\mid点击)$。模型 A 的点击概率 0.40、点后收藏 0.05，联合是 0.02；模型 B 的数字为 0.20、0.18，联合 0.036。单看点击会选 A，若目标是预估每曝光收藏，B 更高。训练时对点后标签明确掩码和归因窗口；还没成熟的收藏反馈不要一律当负例。多个头的损失不同尺度，需要观察每头有效样本量、梯度贡献和离线校准。

重排示例：已排候选为同作者 A 的四条笔记 B1…B4，另有作者 B 的 C1。设置首五条每作者最多两条，能让 C1 提前，但列表可能凑不满，需要约束优先级和回填规则。记录约束移除数与短列表率，同时检查去重是否误伤同作者单主题有多步内容的请求。线上收益未验证，实验记录的是相关与多样性指标的取舍。

练习：为什么简单给新笔记每条加常数可能失败？新笔记质量分布很宽，持久加分会高估陌生笔记。可以按曝光预算分小流量探索，留质量门槛，按内容或新作者分组看覆盖和反馈。

点击、收藏和阅读目标可能冲突，先验证各字段的定义和缺失值，再谈MMoE/PLE。缺失标签应mask，不能统一当零。点击后的收藏条件概率与曝光口径收藏概率不同，建模时必须明确条件。

多任务损失可写为 `Σ λ_t L_t`，权重影响任务梯度；加任务不保证提升，先与单任务比较。更复杂的共享结构只有在负迁移被观察到后才有必要。

重排在候选列表上调节重复、类目和作者多样性。MMR可以在相关性与相似度惩罚间权衡，但两种分数要有合适尺度；固定作者上限也可能误伤相关内容，需要观察质量代价。

## 冷启动策略

新用户：兴趣选择、分时热门、适量探索。新笔记：内容特征召回、合理初始曝光和反馈累积。UCB/Thompson Sampling是探索方法，但日志回放不能简单证明其线上收益，因为未推荐物品的反馈不可见。

当前demo冷用户回退热门，未实现多目标网络或探索策略。这些是可独立选做的扩展。验收时同时报告相关性、覆盖率、多样性和新内容命中；不以单一离线指标替代长期用户价值。
