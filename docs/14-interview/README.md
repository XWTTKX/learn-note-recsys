# 14 · 高频问题与连续追问

1. **召回和排序为什么分开？** 全库逐候选复杂计算成本高，先用可索引模型缩小候选，再做更复杂交互；误召回可被排序修正，漏召回不能。
2. **双塔为什么不能任意加交叉特征？** 候选相关交叉会破坏物品离线编码和用户单次查询的可分解结构。
3. **ItemCF与Swing差别？** ItemCF关注共现及归一化；Swing通过共同用户间的重叠关系抑制偶然共现。具体权重依实现而异，应结合源码解释。
4. **负采样有什么偏差？** 采样分布决定训练目标；随机未观测负例、曝光未点负例各有不同含义。
5. **AUC高但NDCG低？** 全局区分正负不等于每个请求顶部排序好，用户间分数差异也会影响全局AUC。
6. **GAUC怎么定义？** 先按约定分组计算有效组AUC，再按曝光数或其他明确权重平均；说清排除组和分母。
7. **DIN与双塔有什么区别？** DIN对候选条件化聚合兴趣，双塔需独立编码以便高效召回。
8. **多任务一定更好吗？** 不一定，有标签缺失、尺度差异和梯度冲突，需要单任务对照和消融。
9. **新物品怎么处理？** ID没有充分训练时依靠内容与类目特征，并建立探索反馈；报告冷物品分桶效果。
10. **为什么不能把曝光位置直接当推荐特征？** 位置是历史策略结果，会带来偏差和部署时不可用信息；位置偏差建模需要明确因果角色。
11. **用户历史是否允许更新？** 可做静态或滚动评测，但必须固定协议；滚动只允许使用当前时刻之前已观察反馈。
12. **你的指标为何低于上游？** 先比较候选池、数据版本、过滤、测试规模、标签与模型；口径不一致时数字没有直接可比性。

练习：每题回答结论、公式或机制、项目中的具体证据。不要只背模型名称。
