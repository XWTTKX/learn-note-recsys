# 13 · 三阶段实战与实验矩阵

## A：一周建立可信基线

跑合成请求，导入Qilin样例，检查ID与时间字段；用热门和ItemCF比较两种候选协议。产出字段字典、划分说明、数据统计、10个失败案例。toy实验只用于学习，不作为官方benchmark。

## B：两周完成一个模型改进

保留官方划分，选择ID双塔或内容双塔完成训练；验证候选召回；选择LR→DeepFM或LR→DIN的一条排序路线。先用小样本打通，再扩大规模。每次只改一个因素。

## C：一到两周深入一个问题

三选一：困难负采样与分布偏差、内容冷启动、离在线特征一致性。对搜广推面试，能够准确解释一个失败实验往往比堆叠更多模型更有价值。

| 实验 | 固定项 | 改动 | 观察指标 |
|---|---|---|---|
| R0→R1 | 数据、候选池 | 热门→ItemCF | Recall/NDCG/覆盖 |
| R1→R2 | 划分、Top K | 加双塔通道 | 边际Recall、延迟 |
| S0→S1 | 固定召回候选 | LR→DeepFM | AUC/LogLoss/请求NDCG |
| D0→D1 | 同排序分数 | 多样性重排 | NDCG与作者覆盖权衡 |

复制[实验模板](../../experiments/TEMPLATE.md)，先写假设再跑。与搜索项目合计建议六周：基础与数据两周，核心模型两周，工程与面试两周。资源估计在抽样实测后决定，完整百万内容训练不默认适合笔记本。
